Trading Journal

"What did my trading actually make, after fees and funding?"

A trading journal that runs on your own computer. It reads your trade history from your exchanges with read-only keys and shows your real PnL, fees, funding, patterns and notes. Nothing is hosted, so there is no account and no server.

Install it in one prompt

You don't need to type terminal commands. Open Claude Code, Codex, Cursor or a similar coding agent in an empty folder and paste this:

Install and start the trading journal from https://github.com/CryptoGeadas/trading-journal on this computer. Follow the AGENTS.md file in that repository step by step, and offer me the demo data when it's running.

The agent checks Python, installs the journal, starts it and opens it in your browser. It then offers demo data, so you can look around before you connect anything. The repository's AGENTS.md holds the exact steps and the rules the agent must follow. For example, it never asks for your API keys in the chat.

Safety facts

  • Runs on your computer. Only your own computer can open the journal. The page loads nothing from the internet: fonts and the chart library are bundled. The only outside calls go to the exchanges you connect.
  • Your keys stay local. You type API keys into the journal's own Exchanges page, never into a chat. They are stored encrypted in your data folder and used only to read trades.
  • It only reads. The code has no function that places, changes or cancels orders, or moves funds.
  • Use read-only keys. On Binance the journal reads the key's permissions and refuses a key that can withdraw or transfer. Gate.io and Kraken don't report a key's permissions, so there you must make sure withdrawals are off yourself. The setup page says so.

What it does

  • Sync with a button or every 6 hours, with clear errors when an exchange refuses a key.
  • PnL for spot and futures, longs and shorts, with fees in any coin and funding as its own line. Breakdowns by pair, exchange, strategy, emotion, month and week add up to the total.
  • Trades with notes, emotion tags, ratings and up to two chart screenshots each.
  • Patterns: equity curve, win rate, profit factor, streaks, time of day and hold times.
  • Export to CSV, Excel or a ZIP with screenshots, plus one-click backups.
